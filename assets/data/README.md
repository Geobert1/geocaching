# Natural Earth map overlays

These local GeoJSON files provide country boundary lines and coastlines for the optional map overlay.

- `ne_50m_admin_0_boundary_lines_land.geojson` is Natural Earth's 1:50m Admin 0 country boundary linework. The source includes country boundaries on land and offshore.
- `ne_50m_land_coastline.geojson` contains the boundaries of Natural Earth 1:50m land polygons, exported as lines. It includes coastlines and island outlines.

The data is from [Natural Earth](https://www.naturalearthdata.com/), whose data is free to use in any type of project. Geometry was exported to GeoJSON in WGS 84 (EPSG:4326) with three decimal places. See [Natural Earth's terms of use](https://www.naturalearthdata.com/about/terms-of-use/).
